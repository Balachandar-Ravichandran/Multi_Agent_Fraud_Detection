SCORING QUICK REFERENCE
================================================================================

4B Tool Selection (Expected vs Actual)
  1.0: Correct tool chosen
  0.5: Suboptimal but not wrong
  0.0: Wrong tool

5B Tool Calling (Parameter correctness)
  1.0: Parameters valid, results returned
  0.7: Parameters mostly valid, partial results
  0.0: Parameters invalid, query failed

1C Groundedness (Citation quality)
  1.0: 3+ citations per claim
  0.7: 1 citation per claim (minimum acceptable)
  0.0: No citations, hallucination

1A Answer Correctness (Fact accuracy)
  1.0: All facts verified, complete
  0.8: All facts correct, minor gaps
  0.0: Wrong answer

Overall Agent GPA = Average of 4 scores

Target: 0.85+
