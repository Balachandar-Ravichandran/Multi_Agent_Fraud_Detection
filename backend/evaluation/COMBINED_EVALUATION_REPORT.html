What the Scores Mean

✅ Perfect Scores: 4B & 5B (1.00)

Tool Selection & Calling work correctly. The planner understands the question, picks the right tool, and executes it with valid parameters. This is the foundation of agent reliability.

  • Contract questions → RAG ✓
  • Database questions → STORAGE ✓
  • All parameters valid ✓

⚠️ Good Scores: 1C & 1A (0.70-0.80)

Answers are accurate but could be more thorough.

  • Groundedness 0.70: Answers have evidence (not hallucinated), but cite only 1 source. To reach 1.0, need 2-3 citations per claim.
  • Correctness 0.80: Facts are verified as correct, but missing context. A procurement person might misinterpret the answer without full details.

✓ No Critical Failures

Limitations of Agent GPA Evaluation

🔴 Small Test Set

Only 2 Q&A turns evaluated. A comprehensive evaluation would include 10-15 turns covering all tool combinations.

🔴 Not Tested: Logical Consistency

Would require asking the same question 2 different ways and verifying answers agree. Current test has 2 turns with different questions.

🔴 Not Tested: Adversarial Input

Off-topic questions, out-of-domain queries, and edge cases not tested. System may not gracefully refuse inappropriate questions.

Why Both Evaluations Matter

Golden-Set proves the core fraud detection logic is bulletproof — all 9 fraud types detected with zero false positives or false negatives. This is the "Audit Mode" that every invoice goes through.

Agent GPA proves the dynamic Q&A system is reliable for follow-ups — planner picks the right tools, answers are accurate, but could be more thorough. This is the "Q&A Mode" that users interact with for context questions.

Together: A complete system where fraud verdicts are deterministic and reliable, and interactive questions are responsive and grounded.
